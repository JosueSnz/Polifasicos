# Trabalho Final - Circuitos Polifásicos

O intuito desse trabalho é abordar de forma prática a analise simplificada de uma planta elétrica industrial.

## Competências

- Análise de tensões e correntes (linha e fase).
- Análise de cargas e construção de triângulos de potência.
- Calculo do fator de potência.
- Estudo de banco de capacitores em Y ou Δ.
- Estudo de viabilidade econômica e eficiência do projeto.
